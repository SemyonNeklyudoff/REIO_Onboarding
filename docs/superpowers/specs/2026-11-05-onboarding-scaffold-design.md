# Заготовка приложения

Пользователь подтвердил: только запускаемая заготовка Expo + TypeScript без экранов онбординга. Самостоятельный проект в `onboarding-app/`, не связанный с сайтом REIO. Будущий модуль хранится отдельно от демонстрационного приложения; навигацию и сохранение завершения контролирует принимающее приложение.

Выбран официальный минимальный шаблон Expo с TypeScript. Bare React Native требует лишней настройки нативных проектов на этом этапе; шаблон с роутером создаёт ненужную зависимость будущего модуля от навигации.

Результат: стандартный стартовый экран, папка будущего модуля, lockfile, инструкция запуска и интеграции. Без авторизации, сервера, собственных экранов, загрузки на GitHub и подписанных установочных файлов.

Проверка: TypeScript, совместимость Expo зависимостей, экспорт JS-бандлов iOS/Android; проверка запуска по возможности среды с явным указанием ограничений.

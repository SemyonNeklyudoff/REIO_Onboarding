# Модуль онбординга

Публичный вход — `index.ts`, компонент `Onboarding` с обязательными `onComplete` и `onSkip`. Скопируйте эту папку целиком в принимающее приложение. Нужны `react-native-svg`, `react-native-safe-area-context` и `SafeAreaProvider` в корне. Подробный пример подключения и ограничения демонстраций — в корневом README.
